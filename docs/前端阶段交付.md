# 前端阶段交付

日期：2026-10-13。基础版本：main，631eca0。本阶段是基于现有接口的前端底稿，等待团队更新文档与视觉设计后继续。

## 本次完成

- 页面结构、样式、接口请求和交互流程分别放在 index.html、styles.css、api.js、ui.js、app.js。
- 保留同一页面内的连续问答，不再用第二次回答覆盖上一轮；刷新、退出和开始新会话会清除逐字聊天。长期数据仍由后端管理。
- 使用后端已校验的 result.cards 渲染建议卡片，常显标题、证据等级、成本、限制及指南来源，展开查看完整字段。兼容旧 markdown 响应。
- 显示查询与摘要等待状态，阻止问答、回访和记忆管理同时提交；超过 15 秒继续提示处理中。
- JSON 错误、非 JSON 网关错误和网络失败分别转换成可读提示。失败保留输入，用户可手动重试；不会自动重复提交写操作。
- 成功回答之后，若记忆或回访刷新失败，只重试列表加载，不重新提交问答。
- 回答成功与摘要保存失败分别展示。主动关闭记忆时不把未保存显示成技术错误。
- 发送等待期间输入的新草稿不会被成功回包清空；支持 Ctrl / Command + Enter 提问。
- 完成回访预填、取消关联、进展反馈、摘要纠正、删除确认、清空确认及刷新操作。
- 将已被后续记录更新的旧摘要收起，仍可展开查看和管理。
- 登录失效和退出清除页面中的个人内容，并终止浏览器等待中的请求；旧回包不能写回另一个账号的页面。浏览器中止请求不保证服务器端任务撤销。
- 加入键盘焦点、表单标签、状态播报和移动端单列布局。
- 提供双击启动工具，修改前端或模拟适配层后刷新即可生成新的本地预览。
- 静态预览包含正常、澄清、部分支持、无支持、服务错误、网络失败、登录失效、摘要失败及延迟场景。正式页面不包含这些验收开关。

## 本地查看

```sh
python3 scripts/dev_preview.py
```

打开 http://127.0.0.1:8790，点击进入模拟账号。也可双击根目录 `启动前端预览.command`。已启动同一端口时直接打开地址，不重复启动。停止用 Ctrl+C。

模拟环境不使用模型密钥，不连接真实后端，回答只用于验证 UI。正式页面与模拟页面共用前端源文件；构建脚本负责加入独立的模拟适配层。

## 文件交接

| 文件 | 后续维护内容 |
|---|---|
| frontend/index.html | 页面结构、区域顺序、表单与文案 |
| frontend/styles.css | 颜色、间距、字体、布局、响应式样式 |
| frontend/api.js | 同源 JSON 请求与错误、取消处理 |
| frontend/ui.js | 安全的文本渲染、卡片、来源、回答呈现 |
| frontend/app.js | 登录、会话、回访、记忆和请求状态协调 |
| preview/adapter.js | 仅用于模拟预览的接口和场景 |
| scripts/build_preview.py | 正式页面转换为独立的模拟预览 |
| scripts/dev_preview.py | 本机预览启动与刷新更新 |
| tests/frontend_api.test.cjs | 网关错误、失效状态、网络错误及请求取消的回归检查 |

没有修改 backend、模型提示词、指南数据或部署业务逻辑。Docker 原有 COPY frontend 会包含新资产；GitHub Pages 构建已同步复制这些资产。当前改动保留在本地工作树，未推送到远程。
