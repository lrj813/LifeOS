## 打开与启动

最快体验：双击交接包根目录的 `打开交互原型.html`。它打开同目录 `交互原型/index.html`，无需联网、模型密钥或后端。模拟问答与新流程都使用固定场景；点击指南原始出处时才会离开本地页面。

开发预览：在 `LifeOS-source` 双击 `启动前端预览.command`，或运行：

```sh
python3 scripts/dev_preview.py
```

访问 `http://127.0.0.1:8790`。这里是独立模拟环境。本机系统 Python/Git 受到未接受 Xcode 许可的影响，因此本轮使用 Codex 自带运行时，没有替用户接受许可。启动脚本会优先使用本机已有的 bundled Python；移交其他机器时退回 `python3`。

本机可直接运行的命令：

```sh
/Users/blanche/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 scripts/dev_preview.py
```

8790 已有本次预览进程时直接访问，不重复启动；需要另起实例用 `--port 8791`。localhost 地址随进程结束而失效；离线入口不依赖这个进程。

重新导出离线包：

```sh
python3 scripts/export_prototype.py
```

真实联调仍按 README 用 `scripts/run_local.py` 或 Docker，前端 8780、后端 8781。真实模型配置与体验凭据不在交接包内。8790 和离线包的“真实接口模式”用于说明缺口，不能凭这个切换让静态站点拥有后端；实际调用需要同源 `/api`。

## 建议体验路线

1. 欢迎引导可跳过或回看。首页点快捷场景，只预填；确认发送后进入 Agent。
2. 点“交互验收场景”，切换 Bob 空账号；输入搬家示例 → 核对信息 → 选择仅本次或长期保存 → 我的生活。
3. 在我的生活编辑月份，检查同一事件版本与计数；删除需确认，取消不改变数据。
4. 设置分别控制“保存”和“调用”：关闭调用后仍能查看资料，回答与推荐停止引用。
5. 今天 → 推荐详情 → 引用 → 适用条件 → 继续聊；“感兴趣 / 忽略 / 暂不关注”不改变个人事实。
6. 验收场景可选择保存失败、更新失败、版本冲突、推荐重算失败、反馈结果未知等。失败场景会持续生效，重试前选择“正常”。未知结果先查询同一操作，稍后确认也会保留入口。

模拟输入、聊天、档案和反馈只在页面内存中保存，按账号分开；刷新后恢复虚构初始数据。只将欢迎引导偏好存入 sessionStorage，不存用户文本。没有跨设备或跨刷新聊天恢复承诺。

## 真实 / 模拟能力

| 能力 | 模拟模式 | 真实接口模式 |
|---|---|---|
| 四区导航、草稿、欢迎引导、窄屏 | 已实现 | 共用页面与组件 |
| 问答、完整指南卡片、来源 | 固定场景与原始指南 fixture | 保留 `/api/run`、后端校验卡片与 Cookie 请求 |
| 澄清、情境修正、回答版本 | 完整模拟 | 澄清由实际答复展示；结构化情境、原地再生成待接口 |
| 流式停止 | 保留模拟的部分文字 | 只停止浏览器等待，不保证服务端取消 |
| 核对后保存 / 仅本次 | 候选与长期事件分开维护 | 不开放；开启总开关后仍是后端自动摘要 |
| 事件编辑、冲突、分类和计数 | 状态、版本、identity 与失败恢复 | 仍展示长期摘要及真实纠正 / 删除 / 清空 |
| 保存 / 调用两个开关 | 四种组合独立生效 | 现有一个总开关控制长期读写 |
| 最近话题与完整聊天恢复 | 本次内存历史、草稿 | 只根据摘要继续，不伪造逐字聊天 |
| Radar、依据与联动 | 固定指南匹配虚构生活情境 | 只有真实问题回访，Radar 待接入 |
| 指南反馈 | 模拟关注、已完成、无效、撤销 | 保留现有 `done/not_interested/ineffective/undo` |
| 反馈结果未知 | operationId 回查、成功 / 失败分开 | 无回查协议，待后端提供 |
| 单条删除影响 | 只删除当前事件及关联引用 | 如实提示现有后端会清理该账号全部反馈 |

“已实现真实接口模式”只表示前端仍按现有合同调用；本轮没有连接真实模型、验收真实账号权限或运行 Docker。
