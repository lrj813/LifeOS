# LifeOS 当前前端交接 · B07

## 当前状态与入口

当前可开发版本只有 LifeOS-source。电脑浏览器页面，HTML/CSS/原生JavaScript；没有新增桌面客户端、手机端或极光背景。B07是最近完成的视觉统一版本。后端、固定指南及团队原始原型资料仍在源码目录；后端由组员负责。

开发预览：http://127.0.0.1:8792/#/today；对话页为 #/agent。在源码目录双击 启动前端预览.command，或执行 `python3 scripts/dev_preview.py --port 8792`。本机有绑定127.0.0.1的后台预览进程；重启电脑后可用上述命令重新启动。修改frontend/或preview/后刷新即可更新。不要直接修改.preview-site或交互原型内生成的文件。

离线演示：打开上级目录的 打开交互原型.html，必须与交互原型文件夹一起保留。模拟问答不需要模型密钥，模拟记忆刷新会重置。真实模型没有在本轮验收。

## 已确认的首页，避免重复返工

主标题32px、无句号、水平居中、距顶40px。照片物理比例3:4，只使用搬家、列车、工作桌、街巷漫步四张照片循环；八个推荐对象仍有各自ID。卡片标题16px，反馈12px。整个画廊下移16px；输入/历史入口整体距底56px。

大环使用共同相机与原始透视矩阵，拖动和滚轮有惯性。卡片基准平面高度7.4（原8.1，统一缩小约9%），容器保留横向裁切、向下扩展显示边界，避免标题被固定高度截断。不要恢复已经否决的逐卡排位、逐卡fit、镜头后移或整组宽度收纳。图片和动效代码以当前frontend/app.js为准，不重写。

首页只保留情景引导、输入及唯一历史入口。点击卡片进入相应对话并填入可编辑草稿，不自动发送。历史入口进入对话页并临时展开历史列表。首页卡片和下方输入是用户指定的稳定区域，视觉试验应排除这两块。

## 对话页与侧栏

布局与交互借鉴Kimi，配色、内容、功能保留LifeOS。左边缘16px（顶部54px以下）与左上图标悬停会临时展开历史，不挤正文、不抢输入焦点；移出220ms收回，鼠标或键盘焦点仍在侧栏时保留。点击左上图标才固定，固定时正文让出280px，再点可取消。Escape和点击正文可关闭临时侧栏；回首页、退出和切换账号清理状态。

顶部保留侧栏、新对话、当前对话标题和原有更多操作。输入框圆角24px、圆形发送，保留Enter发送、Shift+Enter换行、停止、复制、重新生成、指南、历史、记忆与档案等已有功能；没有增加附件上传或模型切换。收起按钮背景始终透明，用文字颜色表达状态。

## 当前视觉规范

沿用暖白、米色和灰褐：paper #f7f5f0，paper-2 #f0ede6，surface #fffefa，accent #786646。品牌与首页大标题保留原字体；对话与操作采用无衬线。弹窗标题20px、组件标题16px、正文15px、普通控件14px、辅助12px；紧凑侧栏列表13px。按钮圆角8px，列表10px，内容卡片/弹窗16px，输入区24px。工具栏点击区36px，图标20px、线宽1.6。选中状态比悬停更明确。普通内容使用轻边框，临时侧栏/弹窗才使用明显阴影。错误提示不能随辅助信息一起淡化。

## 工作约束与验证

先读AGENTS.md。保留Git历史、原始指南署名与OFL字体许可。frontend是正式页面，preview仅用于隔离模拟，backend/prompts/data由团队统一维护。不要将密钥、账号或运行数据库放入前端或交付包。根目录README的后端介绍是通用资料，当前UI以本文和现有源码为准。

B06功能回归43项通过；B07仅追加CSS，JS与HTML未修改，浏览器已检查对话、侧栏、个人档案弹窗及首页稳定区域。后续业务修改用 `node --test tests/*.test.cjs` 验证；纯CSS小调整做相关浏览器检查即可。离线导出执行 `python3 scripts/export_prototype.py`。
