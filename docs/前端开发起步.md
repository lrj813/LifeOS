# 前端开发起步

这一阶段以当前 LifeOS 代码的功能为基准，先开发页面和交互。

## 启动

在 macOS 双击根目录的 `启动前端预览.command`，或在项目目录运行：

```sh
python3 scripts/dev_preview.py
```

打开 http://127.0.0.1:8790，点击“进入 Alice 预览”。也可使用 alice 或 bob，演示口令 preview。保持终端窗口打开；Ctrl+C 停止。

这是前端模拟环境，不连接 Python 后端或真实模型。演示问答使用固定的手机通知案例，记忆只存在当前浏览器。它用于验证页面交互，不能用于判断 AI 答案质量。

## 修改位置

- `frontend/index.html`：正式页面结构和样式。
- `frontend/styles.css`：样式变量、布局和手机适配。
- `frontend/api.js`：正式接口请求、错误和取消处理。
- `frontend/ui.js`：回答、指南卡片等页面渲染。
- `frontend/app.js`：登录、会话、回访、记忆操作流程。
- `preview/adapter.js`：预览专用的模拟接口。
- `scripts/build_preview.py`：将正式前端生成到 `.preview-site/`。

不要直接修改 `.preview-site/`；它会在启动和源码修改后的页面刷新时重新生成。修改正式前端或模拟适配层后，刷新页面即可重新生成预览。修改构建脚本时需要重启服务。

## 当前页面对应的接口

| 页面操作 | 接口 |
|---|---|
| 登录、退出、恢复账号 | `/api/login`、`/api/logout`、`/api/me` |
| 提交问题、刷新回访 | `/api/run`，分别传 chat 和 home |
| 读取长期记忆 | `/api/memories` |
| 开关记忆、纠正、删除、清空 | `/api/memory-action` |
| 查看完整指南条目 | `/api/guide-entry`，后端已有，模拟环境提供 03-01 示例条目 |

接入真实后端时使用仓库原有的本地或 Docker 运行方式。模型密钥由后端读取，不放进前端。

## 设计图到手前

先熟悉登录、提问、建议展示、回访和记忆管理的现有流程，记录移动端、等待、错误和重复提交的体验问题。颜色、字体和最终布局等待团队设计图；新增功能或改变登录策略先与团队对齐。

Proma 核心的集成位置和对应源码仍需团队确认。目前仓库的运行核心是 Python AgentService，不能把当前预览当作 Proma 集成验收。

完整改动、验证结果与下一阶段交接见 [前端阶段交付](前端阶段交付.md)。
