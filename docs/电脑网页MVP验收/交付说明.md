## 当前范围

只做电脑浏览器网页。设计风格、规范和图片尚未收到，沿用临时黑白灰。首页支持原生横向滚动、卡片吸附和左右切换；卡片叠放、缩放、自动轮播等最终动效等待设计稿。本轮不开发手机端或桌面安装包。

只读理解 Figma 中“交互 MVP 定稿”旁的12张视觉关键页面与功能思维导图；原 Figma 未修改。新原型和本次用户确认优先于四区首版的旧交接。

## 已完成

- 首页推荐与轻输入、统一对话，取消旧四区导航和欢迎引导；历史侧栏默认收起，头像进入个人档案与设置。
- 历史搜索、新建、恢复、重命名、调整现有情境、删除；分组随有内容的对话出现，无预创建的六个空分类。
- 模拟模式自动保存用户明确表达的事情，研究或咨询意图不等于生活计划；未知预算与日期不填猜测值。同一事情后续补充更新原记录，重试和重新生成不重复创建。
- 档案只展示事情名称、删除与继续聊，取消记忆编辑、确认保存和保存/调用开关。保存成功才提示；保存失败不影响回答，支持单独重试。
- 继续聊先展示轻量摘要，旧消息默认折叠；原对话已删除时携带仍有效的记忆开新对话。读取失败不冒充历史已删除。
- 推荐只保留“不想看”，普通刷新不让已移除条目重新出现，不删除个人事实。多条结果未知反馈分别保留查询入口。
- 从推荐继续聊传递准确推荐ID，通勤指南不会漂回租房条目。推荐类别为固定数据演示，不是最终六类命名。
- 分段回复仅更新当前文字节点，保留输入焦点、下一条草稿和阅读位置。停止保留未完成内容，重试复用同一问题轮，重新生成保留上一版。
- 普通回复不默认展示证据面板；真实指南仍能打开完整内容与原始出处，保留来源和许可。

## 真实与模拟边界

| 能力 | 当前实现 |
|---|---|
| 登录、指南问答、摘要、问题回访、删除摘要 | 真实模式继续用现有API；本轮未连接真实模型验收 |
| 首页情境推荐、持久化历史、服务器删除对话、结构化自动记忆 | 新完整流程为隔离模拟；真实模式明确显示接口缺口 |
| 真实模式历史 | 只保留本页会话，刷新后清除；“从本页移除”不声称服务器删除成功 |
| 真实模式自动记忆 | 后端已有摘要保存规则；已关闭的配置不会被前端强行开启 |
| 停止 | 模拟可取消；真实模式只中止网页等待，服务端可能仍处理 |
| 联网 | 仅等待/恢复流程模拟，不伪造搜索结果；真实搜索由后端接入 |
| 数据 | 模拟会话、输入、记忆只在页面内存，按虚构账号隔离，刷新重置 |

六类正式情境名称、联网触发与回答范围待团队确认。后端新合同需要确认对话列表/分页/搜索/摘要/重命名/分组/删除、自动事情记忆及部分失败、推荐对象与“不想看”、生成取消/再生成、反馈操作回查。旧“确认保存/独立开关”缺口不再是当前MVP UI任务。

## 入口与文件

最快体验：交接根目录 `打开交互原型.html`，离线模拟不需要模型密钥。工具没有直接验证 file 协议，HTTP使用同一构建资源已验证。

开发启动（在 `LifeOS-source`）：

```sh
python3 scripts/dev_preview.py --port 8792
```

打开 `http://127.0.0.1:8792`。本机系统 Python 若要求 Xcode 设置，可使用：

```sh
/Users/liang/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 scripts/dev_preview.py --port 8792
```

也可以双击源码内 `启动前端预览.command`（默认8790）；已占用时使用上面的8792，不停止不明服务。源码在 `frontend/`，不编辑导出目录。
